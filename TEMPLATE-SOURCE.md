# Template source and reuse

## Actual source package

- Template: [TemplateMo 591 Villa Agency](https://templatemo.com/tm-591-villa-agency)
- Public original preview: [Villa Agency live template](https://templatemo.com/templates/templatemo_591_villa_agency/)
- Downloaded ZIP: [templatemo_591_villa_agency](https://templatemo.com/download/templatemo_591_villa_agency)
- Download and inspection date: 2026-10-26.
- Source archive was downloaded into a temporary working directory and inspected before adaptation. Only the source files actually used by this single-page adaptation were carried into this directory. Template photographs, icons, sample listings, prices, addresses, testimonials, and unnecessary JavaScript were not imported.

## Source code actually retained

`vendor/villa-agency-base.css` contains selected original declarations from `assets/css/templatemo-villa-agency.css` in the downloaded ZIP. The original TemplateMo attribution is retained at its beginning. The selected rules include `.header-area`, `.main-nav`, `.nav`, `.main-banner .item`, `.category`, `.section-heading`, `.featured .left-image`, `.featured .info-table`, `.properties .item`, and `.main-button`. Responsive rules for those components are retained. Template-image background rules, preloader, unused Owl controls, secondary pages, tabs, and accordion styles are excluded. Brand and responsive changes are applied separately in `styles.css`.

The HTML adapts the source header structure and full-width banner, its Bootstrap `.container`/`.row` structure, the featured section's `.col-lg-4` / `.col-lg-5` / `.col-lg-3` arrangement, and the property section's `.item` / `.category` / content layout. The professional facts now refer to Marci, and original property cards become original buying/selling guidance. This is a source-code adaptation of the downloaded template, rather than a page that merely cites its visual direction.

`vendor/bootstrap-grid.css` contains the actual original container, row, and responsive-column declarations selected from the package's `vendor/bootstrap/css/bootstrap.min.css`. The version shipped in this package identifies itself as **Bootstrap 5.3.0-alpha1**. Its copyright and MIT notice are retained, and the complete matching version's license is included as `vendor/BOOTSTRAP-LICENSE.txt`. The full Bootstrap stylesheet, JavaScript, jQuery, Font Awesome, animation library, Owl Carousel, and Isotope were unnecessary for the retained components and are not included.

All page images instead resolve to official Marci Metzger assets in `assets/`, whose source record is `assets/sources.json`. Google Fonts supplies Poppins and DM Serif Display; fallback system/serif fonts are specified.
