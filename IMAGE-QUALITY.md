# Official image quality

All 21 original image assets are included locally in `assets/`. Source URLs, dimensions, and section mappings are recorded in `assets/sources.json`.

The hero uses the genuine 2560 × 1700 Mountain Falls photograph. The two 1024px gallery photos previously used as full-width slides were removed from the hero; those photographs remain in their original gallery positions. Gentle motion pans the original photograph without zooming it larger.

The seven original gallery files are 1024 × 682 or 1024 × 683. Published gallery metadata and official image-service metadata confirm these dimensions. Requests for 2048px versions return the exact same files; larger genuine gallery originals were not found. The source files were not artificially enlarged or replaced with generated images.

The wide gallery card is capped at 1024 CSS pixels. The lightbox uses each image's intrinsic size with responsive maximum dimensions, and hover enlargement has been removed. High-density screens still cannot gain detail that is absent from a 1024px original. A truly higher-resolution gallery would require better original files from the owner or photographer.

The portrait is 1632 × 2449. Other major source photographs range from 1254px to 2560px wide and are used in smaller cards. Original source files are preserved without local recompression.
