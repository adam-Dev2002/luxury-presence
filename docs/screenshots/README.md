# Add browser screenshots after deployment

Capture the real deployed page at these sizes:

1. Desktop: 1440 × 900.
2. Tablet: 768 × 1024.
3. Phone: 390 × 844.

Include the hero, photo gallery, footer, and open mobile menu where useful. In Chrome, open Developer Tools, enable the device toolbar, enter the size, and use the command menu's screenshot option. Review for overflow, unreadable text, image cropping, and overlapping controls before saving captures.

Suggested filenames: `desktop-home.png`, `tablet-home.png`, `mobile-home.png`, `desktop-gallery.png`, and `desktop-footer.png`. Then embed actual captures in the repository README. Do not describe the photography contact sheet as a website screenshot.
